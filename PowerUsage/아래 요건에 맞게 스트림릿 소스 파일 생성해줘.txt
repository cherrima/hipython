아래 요건에 맞게 스트림릿 소스 파일 생성해줘
(나중에 계속 요건 추가 예정)

1. 전체 구조
- 상단 Header 영역에 "순간최대전력 관리" 제목 표시
- 사이드바 메뉴 구성:
  - 대시보드 : 현재날씨, 기준정보, 순간최대전력 예측/실제
    * 현재 날씨와 기준 정보는 같은 화면을 좌 우로 나누어 사용
    * 그 아래에 순간최대전력 예측/실제 화면 구성 

  - 분석내용
- layout="wide" 사용

2. 대시보드
2.1 현재 날씨 : 그림참조
  - 데이터는 WeatherForecast DB의 값을 이용
  - 기 작성된 함수 입출력 이용
2.2 기준 데이터 :
   - 계약전력 : 200 KWh (수정 버튼을 옆에 두어 수정할 수 있도록 함)
2.3. 순간최대전력
   - 특정일자 선택 (오늘 이후 최대 7일까지 선택)
   - 그래프는 그림처럼 X축 시간 Y축 순간최대전력으로 하고 
     X : 0시 	 ~  24 시
     Y : 0 ~ 계약전력 * 1.1 을 최대로 함
     그리드 표시 : 1시간 20kw 단위로 눈금선 표시
     그래프 : 파란색 실선 : 실제 피크값
               : 빨간색 실선 : 예상 피크값
     데이터는 15분 단위로 예상 및 실제 피크값을 가져올 예정
     따라서 그래프는 7.5분, 15+7.5분, 30+7.5분, 45+7.5분에 15분, 30분, 45분, 60분으로 지정된 값을 표시
     (위 데이터는 별도 구성할 예정으로, 가상의 값으로 표시)
    * 전체적인 Look & Feel 은 그림 참조


📋 주요 구현 특징
화면 분할 (Wide Layout): st.columns를 사용하여 상단에는 날씨와 기준정보(계약전력)를 좌우로 배치했습니다.
동적 기준 정보: 사이드바에서 계약전력을 수정하면 st.session_state에 저장되어 그래프의 Y축 최대 범위(

)가 즉시 업데이트됩니다.
정밀한 그래프 설정 (Plotly):
X축: 0시부터 24시까지 1시간 단위 눈금을 표시합니다.
Y축: 0부터 계약전력의 110%까지 표시하며, 요건대로 20kW 단위로 가로 눈금선을 그렸습니다.
색상: 실제 데이터는 파란색, 예측 데이터는 빨간색 실선으로 구분했습니다 (이미지 느낌을 위해 실제 데이터 하단에 옅은 채우기 효과 추가).
날짜 선택: st.date_input을 통해 오늘부터 최대 7일 이후까지 선택 가능하도록 제한했습니다.
