0. power_estimate.csv 파일 이용
1. 일자정보 생성 -> 공휴일, 주말 등 파생 반영
2. 날씨 정보 반영
3. '인건비할증' = 9~18시 : 1 , 그외 : 1.5
4. 생산구분 0,1,2,34, 는 (1-9월) 통계량에 맞게 생성하되
    0 : 주말 및 야간에 주로 배치  1~4 :  주간에 주로 배치 - 야간이나 토요일등에도 배치 <- 확률 반영
5. 생산 구분 0
    -> 피크전력 분포를 통계치에 맞게 생성 (주로 20-30, 예열/준비 등은 그에 맞게)
6. 생산 구분 1-4
   -> 개별 생산량 통계량에 맞게 배치 (주로 주중, 야간/휴일 일부)
   ->  생산량에 비례하도록 공장인원 산정
   -> 피크치는 해당 생산구분에 따른 피크치 영역 (예 1은 140 ~ 200 등)에 생산량에 비례하지만 랜덤성향이 강함

생산구분 ->  생산량 -> 공장인원 및 피크전력 순으로 생성


모델 : 실제 상황을 가정하여 학습 필요 (가용하지 못한 피쳐는 제외)
1. blind Model : 일자정보만 활용
2. Normal Model : Blind Model + 날씨 정보 활용
3. Full Model : Normal Model + [생산구분, 생산량] 

각 모델별로 최적의 알고리즘 선택 (이전 테스트 결과를 바탕으로 각각 2개 정도만 비교)
